HOME REDESIGN · V2

核心动作回到中心，两套主题一起给

功能依旧一个不动：是否刷手机、入睡、起床、目标、周报跳转、清空数据。这版把「这一晚」重新做成唯一的视觉主角，并新增可切换的浅色 / 深色主题。

  • 01
    大圆回来了，但不再是红牌
    420rpx 告警红大球 → 188px 状态球，刷了是暖珊瑚，没刷是薄荷，点击切换逻辑不变
  • 02
    它是页面唯一的中心
    标题压到 24px 一行、去掉副标与胶囊，视线 1 秒落到「是 / 否」
  • 03
    两次录入合成一行
    两张并列白卡 → 一条 72px 高的时间行，退到第二层级
  • 04
    空状态变成邀请
    灰色「未填写」 → 薄荷色「＋ 添加」，一眼知道可点
  • 05
    0 天做成期待，且不造假
    「已达标 0 天」黑卡 → 7 段周进度条，只用 metCount / completeCount，不虚构连续打卡
  • 06
    左上角一键换肤
    浅色暖纸 / 深色夜空，同一套语义色变量；是/否的功能色两版一致，记忆选择
